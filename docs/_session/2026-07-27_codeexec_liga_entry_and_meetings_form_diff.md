# C. Форма встреч

## C1. Город и формат — теперь у любой встречи

Оба поля лежали внутри `{formData.is_public && …}`, то есть у непубличной встречи
город указать было негде — хотя от города зависит часовой пояс
(`resolveCityTimezone`), а он нужен любой встрече, публичной или нет.

Вынес «Формат встречи» и «Город» наверх, в блок с названием, датой и временем —
двумя колонками. Обработчик тот же: переключение на «Онлайн» подставляет город
«Онлайн» и блокирует поле, обратно — очищает.

Под публичным переключателем остались только те поля, которые видно в общем
расписании: описание, обложка с превью и фокусом, стоимость, ссылка для
регистрации и «показывать онлайн-встречу только во вкладке Онлайн / во всех
городах» (это про витрину, у непубличной встречи смысла не имеет).

## C2. Завершённую встречу теперь можно править

В карточке завершённой встречи была только кнопка «Изменить итоги» — базовое
после завершения не правилось совсем, опечатка в городе оставалась навсегда.
Добавил рядом «Редактировать встречу»: открывается та же форма планирования.

Под этим лежал капкан, который надо было снять в первую очередь. `handleSavePlan`
жёстко писал `status: 'planned'` в сохраняемый объект — то есть правка города у
завершённой встречи откатила бы её в незавершённые вместе с итогами и семенами.
Теперь статус сохраняется, а не переписывается:

```js
// Статус сохраняем, а не переписываем на 'planned': из этой же формы
// теперь правят завершённую встречу (город, название), и жёсткое
// 'planned' откатывало бы её в незавершённые вместе с итогами.
// Для копии и переноса статус уже выставлен в buildDraftFromMeeting.
status: formData.status || 'planned',
```

Копия и перенос отменённой не задеты: `buildDraftFromMeeting` и так проставляет
`status: 'planned'` явно.

## C3. «Город обязателен» — проверил, всё уже правильно

Проверка и раньше стояла ровно там, где надо:

```js
if (data.is_public) {
    …
    if ((data.meeting_format || 'offline') !== 'online' && !data.city) missing.push('Город');
```

То есть город требуется только у публичной и только не-онлайн встречи; у гибрида
требуется тоже — и это верно, у гибрида есть физическое место. У непубличной
город остаётся необязательным, что теперь особенно важно: поле у неё появилось,
но заполнять его никто не заставляет. Менять ничего не стал.
