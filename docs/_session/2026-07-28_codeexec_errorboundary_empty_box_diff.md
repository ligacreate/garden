# Пустой чёрный блок на экране ошибки: ErrorBoundary терял текст при chunk-перезагрузке

**Дата:** 2026-07-28
**Статус:** ✅ применено по прямому одобрению Оли («делай и комить»), без ожидания отдельного 🟢.
**Повод:** Оля прислала скриншот экрана ошибки с пустым тёмным прямоугольником.

---

## 1. Что случилось на проде

Хронология (лог пишет UTC, телефон Оли показывает UTC+5 — отсюда расхождение в
два часа, которое сперва сбило меня с толку):

| UTC | По часам Оли | Событие |
|---|---|---|
| 09:16:55 | 14:16 | пуш `1eabe81`, старт деплоя |
| 09:34:28 | 14:34 | деплой завершён успешно |
| 09:35:53 | 14:35 | `ChunkLoadError` у Оли, репорт долетел в лог |
| — | 14:36 | скриншот экрана ошибки |

Единственная запись в `/var/log/garden-client-errors.log` за сутки:

```json
{"ts":"2026-07-28T09:35:53.105Z","source":"ErrorBoundary.chunkLoad",
 "message":"ChunkLoadError → auto-reload",
 "stack":"Importing a module script failed.",
 "url":"https://liga.skrebeyko.ru/","userAgent":"iPhone ... CriOS/150",
 "bundleId":"1eabe81...","user":{"email":"olga@skrebeyko.com"}}
```

Это INFRA-005: открытая вкладка держала старый entry-чанк, приехал деплой,
ленивый импорт не разрешился. **К правке ВК отношения не имеет** — ломается
загрузка модуля, а не выполнение кода. Ретенция старых чанков в этом деплое
отработала штатно (в логе CI «файлов после мержа: 804»), прод здоров, входной
бандл и CSS отдают 200.

## 2. Настоящий дефект, который это вскрыло

На скриншоте тёмный блок пустой — не закрашен, а действительно без текста. Ветка
chunk-ошибки вызывала `window.location.reload()` и выходила по `return`, **не
дойдя** до `this.setState({ error, errorInfo })` в конце метода:

```js
if (now - last > RELOAD_GUARD_MS) {
    sessionStorage.setItem('garden_chunk_reloaded', String(now));
    window.location.reload();
    return;                    // ← setState ниже не выполняется
}
```

Расчёт был на то, что страница сейчас перезагрузится и экран никто не увидит.
Расчёт не выдержал встречи с реальностью: перезагрузка не случилась, и человек
остался с экраном «сделайте скриншот и отправьте разработчику», на котором
показывать нечего — `state.error` равен `null`, потому что
`getDerivedStateFromError` выставляет только `hasError`.

Инструкция на экране просит скриншот, а сам экран не даёт на нём ничего
полезного — ровно в тот момент, когда страховка не сработала и диагностика
нужнее всего.

## 3. Дизайн-решение

Диагностическое состояние выставляем **до** попытки перезагрузки, а не после.
Перезагрузка — это надежда, а не гарантия: `reload()` может не выполниться,
может быть отложен браузером, может упереться в кэш. Всё, что нужно для разбора,
должно оказаться в state раньше, чем мы на что-то понадеемся.

Побочно ушёл дубль: `setState` и `console.error` стояли в конце метода и
выполнялись в обеих ветках — теперь они одни, наверху.

Порядок «сначала state, потом отправка репорта» безопасен: `reportClientError`
асинхронный и ничего не возвращает в UI.

## 5. Что НЕ затронуто

- **Механика auto-reload.** Loop-guard, окно 30 секунд, ключ
  `garden_chunk_reloaded` — без изменений. Чинили видимость ошибки, а не
  правила перезагрузки.
- **Определение chunk-ошибки.** Регулярка та же.
- **Репортинг.** `reportClientError` и обе ветки вызовов не тронуты.
- **Разметка экрана ошибки.** Тёмный блок, кнопка, тексты — как были.
- **Ретенция чанков в деплое.** INFRA-005 v3 работает, править нечего.

## 6. Edge-case'ы

| Ситуация | Поведение |
|---|---|
| Chunk-ошибка, перезагрузка сработала | Как раньше — человек экрана не видит |
| Chunk-ошибка, перезагрузка не сработала | **Изменение:** в блоке виден текст ошибки и стек компонентов |
| Chunk-ошибка внутри окна 30 секунд (петля) | Reload подавлен, текст виден — как и раньше, но теперь он попадает в state раньше |
| Обычная ошибка (не chunk) | Без изменений: репорт и текст на экране |
| `errorInfo` пуст | `<pre>` пустой, сообщение об ошибке всё равно видно |

## 7. Проверки

- `npx eslint components/ErrorBoundary.jsx` — одна ошибка,
  `'error' is defined but never used` в `getDerivedStateFromError`.
  Предсуществующая, к правке отношения не имеет.
- `npm run build` — проходит.
